A newspaper front page summing up Friday 20 November 2026 in one image: 35 dated, sourced stories across 7 regions, with 13 hand-drawn illustrations, a key-numbers strip and a date check. The image is drawn at build time by draw.py (Pillow) into entry.png; main.py only copies it to the output directory.

## Run it

```sh
python3 draw.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
